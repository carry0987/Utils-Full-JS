# Utils-Full-JS Docs

Documentation site for `Utils-Full-JS`, the browser-first wrapper package built on top of `@carry0987/utils/browser`.

## Stack

- Docusaurus 3
- React 19
- TypeScript
- pnpm

## Requirements

- Node.js 24 or newer
- pnpm

## Development

Install dependencies:

```bash
pnpm install
```

Start the local docs site:

```bash
pnpm start
```

Build the production site:

```bash
pnpm build
```

Serve the built site locally:

```bash
pnpm serve
```

## Useful Commands

```bash
pnpm typecheck
pnpm lint
pnpm clear
```
